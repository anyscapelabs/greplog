## ID Detail View: Modal vs Full Page vs Drawer

**Decision: Right slide-in drawer**

| Approach | Verdict | Reason |
|----------|---------|--------|
| Modal | ❌ | Destroys scroll position, covers the table, poor for scanning multiple rows |
| Full page | ❌ | Route complexity (`/logs/:id`), back-navigation hassle, loses table context. Overkill for v0.1 |
| Drawer | ✅ | Industry standard (Datadog, Grafana, Sentry). Preserves table context, fast open/close, side-by-side comparison, natural for "View" action |

**Implementation**: Click "View" → 500px right panel slides in. Close via X, ESC, or click-outside. Highest priority UX build for v0.1 after removing dead tabs.

## Log Detail Drawer Content

```
┌─────────────────────────────────┐
│ Log Detail              [X]     │  <- sticky header
├─────────────────────────────────┤
│                                 │
│  Level:  ERROR                  │  <- badge, color-coded
│  Log ID: log_a1b2c3d4           │  <- copyable UUID
│  Timestamp: 2026-07-17 14:23:11 │  <- full ISO format
│                                 │
│  ── Message ──                  │
│  Connection pool exhausted      │  <- full text, no truncation
│                                 │
│  ── Context ──                  │
│  Service:    db                 │
│  Logger:     db.connection      │
│  File:       src/db/pool.ts     │
│  Status:     503                │
│  Response:   2.3s               │
│  Correlation: corr-9x8a2b      │
│                                 │
│  ── Raw Log ──                  │  <- collapsible section
│  {"level":"error",...}          │  <- full JSON payload
│                                 │
│  └─ Copy ID │ Copy JSON ┘       │  <- footer actions
└─────────────────────────────────┘
```

**Required fields (new in bold):**
`id`, `timestamp`, `level`, `service_name`, `logger_name`, `message`, `correlation_id`, `file`, `response_time`, `status_code`, **`raw_payload`**, **`environment`**, **`host`**
