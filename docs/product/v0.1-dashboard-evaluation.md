## ID Detail View: Modal vs Full Page vs Drawer

**Decision: Right slide-in drawer**

| Approach | Verdict | Reason |
|----------|---------|--------|
| Modal | ❌ | Destroys scroll position, covers the table, poor for scanning multiple rows |
| Full page | ❌ | Route complexity (`/logs/:id`), back-navigation hassle, loses table context. Overkill for v0.1 |
| Drawer | ✅ | Industry standard (Datadog, Grafana, Sentry). Preserves table context, fast open/close, side-by-side comparison, natural for "View" action |

**Implementation**: Click "View" → 500px right panel slides in. Close via X, ESC, or click-outside. Highest priority UX build for v0.1 after removing dead tabs.

## Log Detail Drawer Content

Right slide-in drawer (same UX as Service / Error detail drawers). Close via X, ESC, click-outside.

### Log Level-Dependent Rendering

| Level | Header Badge Color | Emphasis | Actions |
|-------|-------------------|----------|---------|
| `error` | Red `var(--error)` | Show full stack trace, highlight correlation_id | "View Related Errors" link |
| `critical` | Red `var(--error)` + pulse | Same as error + show affected services | "View Related Errors" link |
| `warn` | Amber `var(--warn)` | Show message prominently, collapse trace if empty | Standard |
| `info` | Blue `var(--info)` | Compact view, raw payload collapsed by default | Standard |
| `debug` | Gray `var(--text-secondary)` | Raw payload expanded by default (debug context matters) | Standard |

### Content Sections Detail

#### Header
| Element | Example | Behavior |
|---------|---------|----------|
| Level badge | `🔴 ERROR` | Color-coded pill (red/amber/blue/gray) |
| Log ID | `log_a1b2c3d4` | Copyable — click to copy UUID to clipboard, flash "Copied!" |
| Timestamp | `2026-07-17 14:23:11` | Full ISO format — timezone can be added later |

#### Message
- Full message text, no truncation (unlike the table cell)
- Larger font size than metadata (16px vs 13px)
- If a multi-line message exists, show all lines
- Search term highlighting if opened from a search query

#### Context (key-value list)
| Field | Example | Copyable? | Notes |
|-------|---------|-----------|-------|
| Service | `db` | No | Clickable → filters Logs page to this service |
| Status Code | `503` | No | Color-coded (5xx=red, 4xx=amber, 3xx=blue, 2xx=green) |
| Response Time | `2.3s` | No | |
| Logger | `db.connection` | ✅ Yes | |
| File | `src/db/pool.ts:142` | No | Clickable — opens in editor (vscode://file/...) |
| Correlation ID | `corr-9x8a2b` | ✅ Yes | Primary linking identifier across services |
| Environment | `production` | No | |
| Host | `db-03.internal` | ✅ Yes | |

#### Stack Trace (collapsible)
- **Visible by default** for `error` and `critical` levels
- **Hidden by default** for `warn`, `info`, `debug`
- Monospace font, line numbers, file links
- Empty state: "No stack trace available"

#### Raw Log Payload (collapsible)
- **Visible by default** for `debug` level (debug context is the whole point)
- **Hidden by default** for all other levels
- Syntax-highlighted JSON with collapsible nested objects
- Monospace, scrollable if payload is large
- "Copy JSON" button in footer copies the full payload

#### Related Errors (mini table)
- Only shown when `correlation_id` is present
- Errors sharing the same correlation_id
- 5 most recent
- Columns: timestamp, error_code, message
- Click row → navigates to Errors page filtered by correlation_id
- Empty state: "No related errors found"

#### Footer Actions
| Action | Behavior |
|--------|----------|
| Copy ID | Copies `log_a1b2c3d4` to clipboard |
| Copy JSON | Copies full raw payload JSON to clipboard |
| View Related Errors → | Navigates to `/errors?correlation_id=corr-9x8a2b` |
| View in Logs → | Closes drawer, scrolls to this row in table |

### Empty States
- **No stack trace:** Show muted text "Stack trace not captured for this log level"
- **No raw payload:** Show muted text "No additional payload data"
- **No related errors:** Show green checkmark + "No related errors found for this correlation ID"
- **Missing file:** Omit the file row entirely or show "Unknown source"

### Level-Specific Behavior Matrix

| Section | error | critical | warn | info | debug |
|---------|-------|----------|------|------|-------|
| Stack trace | Expanded | Expanded | Collapsed | Collapsed | Collapsed |
| Raw payload | Collapsed | Collapsed | Collapsed | Collapsed | Expanded |
| Related errors | Shown | Shown | Shown | Shown | Hidden |
| File link | Shown | Shown | Shown | Shown | Shown |
| Emphasis | Full context | Full context + pulse | Message-focused | Compact | Debug context
